# Spotify Music Trends & Insights Analytics Dashboard

An end-to-end data analytics and visualization dashboard built to analyze streaming patterns, artist performance, track popularity, and audio traits across Spotify's extensive music catalog. This project processes and visually maps key metrics—such as explicit content distribution, track durations, release timelines, and album popularity trends—to deliver actionable insights into contemporary listening habits.

# Key Metrics & Analytics

* Catalog Scale: Processes a dataset containing 789 distinct songs and 342 unique artists.


* Audio Profile Insights: Measures track length trends with an overall average song duration of 3.28 minutes.


* Content Classification: Categorizes songs by explicit vs. non-explicit content (11K non-explicit vs. 17K explicit instances analyzed).


* Album Distribution: Breaks down song distribution across album types, highlighting major categories like single releases, standard albums, and re-recorded editions (e.g., *Taylor's Version*).



# Featured Dashboards & Visualizations

* Top Artists & Songs: Displays leading artists by track count—headed by Taylor Swift, Charli XCX, Travis Scott, and Drake—alongside individual track analysis.


* Popularity Metrics: Tracks average popularity scores across release months, quarters, and album popularity levels.


* Temporal Trends: Maps distinct song distributions and release volumes month-by-month over the year.


* Track Deep-Dives: Details individual song metrics, artist collaborations, and popularity rankings for top hits (e.g., *I Wanna Be Yours*, *Cruel Summer*, *As It Was*, and *Starboy*).

# Problem Statement
Currently, Spotify’s raw “Top 50” dataset is limited to lists and rankings, making it difficult for stakeholders to see patterns and take insights quickly.
From the screens, the key problems solved are:

•	No clear KPI monitoring → Dashboard provides quick summary of total songs, artists, popularity, duration, etc.

•	Lack of explicit vs non-explicit analysis → Users can compare how explicit songs perform vs non-explicit.

•	Difficulty in tracking song/album distribution → Visuals show breakdown by album type and release year.

•	Trend visibility missing → Popularity and distinct songs trends are shown over time (monthly & yearly).

•	Artist vs Song level insights not connected → Drill-down pages for Artists and Songs connect overview insights to detailed records.

•	Decision-making gaps → Marketing and curation teams can now identify which artists/songs to promote, trends to follow, and which content resonates with audiences.
